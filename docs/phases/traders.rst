Phase des marchands
===================

#. Le joueur avec le :ref:`turn_counter_intro` commence;
#. Il choisit le personnage de son **marchand** qui **effectue ses actions**;
#. Il pose un **jeton d'activation** sur la carte de ce marchand;
#. Il passe la main au **joueur suivant** (dans le sens horaire);
#. Chaque joueur **procède de même** jusqu'à épuisement des marchands de tout les joueurs;

Une fois que tout les marchands ont été joués, la phase des marchands est terminée.
